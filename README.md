# Kimia Farma Performance Analytics (2020-2023)

## 📌 Project Overview
This project is part of the Rakamin Academy x Kimia Farma Big Data Analytics Virtual Internship Program. The goal is to evaluate Kimia Farma's business performance from 2020 to 2023 using BigQuery and Google Looker Studio.

## 📂 Dataset
Four datasets were provided and imported into BigQuery:
| Table | Description |
|---|---|
| `kf_final_transaction` | Customer transaction data |
| `kf_product` | Product and pricing data |
| `kf_kantor_cabang` | Branch location and rating data |
| `kf_inventory` | Product stock data per branch |

## 🛠️ Tools
- **Google BigQuery** — data storage and SQL querying
- **Google Looker Studio** — dashboard visualization
- **GitHub** — version control and documentation

## 📈 Key Findings
- Total transactions: 672.46K across 2020–2023
- Total revenue: Rp 347M | Total profit: Rp 98.5M
- Jawa Barat dominates both revenue and total transactions
- 75.7% of profit comes from products priced above Rp 500K
- Revenue peaked in 2022 and slightly declined in 2023

## 💡 Recommendations
1. Expand market penetration outside Java
2. Investigate revenue decline in 2023
3. Improve transaction service quality in high-rated but low-transaction-score branches
4. Prioritize stocking and promotion of premium products (>Rp 500K)
